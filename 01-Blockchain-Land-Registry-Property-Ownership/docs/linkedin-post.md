🚀 Built a Blockchain-Based Land Registry & Property Ownership System

I recently completed an educational blockchain prototype that demonstrates how property records can be made more traceable and tamper-evident using Solidity smart contracts.

### What I implemented

🔹 Role-based property registration
🔹 Surveyor verification workflow
🔹 Owner-controlled ownership transfer
🔹 Ownership history and blockchain events
🔹 Document integrity verification using cryptographic hashing
🔹 Access-control and invalid-state security checks
🔹 16 automated Hardhat tests
🔹 Local Ethereum-compatible blockchain deployment
🔹 Interactive React/Vite DApp frontend

### Tech Stack

Solidity • Hardhat • Ethers.js • React • Vite • JavaScript • Local EVM

### Demo flow

Property Registration → Verification → Ownership Transfer → Ownership History → Security Validation

All records in the project are synthetic and run on a local test blockchain. The prototype does not claim to create legally valid property ownership.

This project helped me strengthen my understanding of smart contracts, access control, events, blockchain state, cryptographic hashing and Web3 frontend integration.
