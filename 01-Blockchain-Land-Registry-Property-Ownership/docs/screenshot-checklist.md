# Final Screenshot / Evidence Checklist

For a recruiter-facing presentation, keep the main visual story to six screenshots:

| # | Suggested filename | What it proves |
|---|---|---|
| 01 | `01_dashboard.png` | Product overview and live blockchain state |
| 02 | `02_property_registration.png` | Registrar property-registration workflow |
| 03 | `03_property_verification.png` | Surveyor verification, on-chain data and document hash |
| 04 | `04_ownership_transfer.png` | Owner A transferring a verified property to Buyer B |
| 05 | `05_ownership_history.png` | New owner and immutable ownership history |
| 06 | `06_security_and_testing.png` | Security/integrity proof and automated validation |

## Do not capture

- Private keys
- Personal wallets
- Real property documents
- Real personal identity data
- Browser extensions showing secrets

The Hardhat private keys are publicly known demo keys and must never be used on a real network.
